DECISION PATH

Defense chain

  1. 01
    Project by source

    Only the bounded evidence shape for Suricata or Wazuh enters the model boundary.

  2. 02
    Encapsulate untrusted values

    Attacker-controlled strings are data inside explicit boundary markers, never trusted instructions.

  3. 03
    Validate the complete response

    The entire JSON response must match the exact contract before a verdict is accepted.

  4. 04
    Check the canary

    Raw and decoded output are scanned before the decision is persisted.

EVIDENCE SCOPE

What this page claims

This is a posture view of controls in the shipped classifier. The dashboard does not currently persist canary-hit history, schema-rejection counts, suspicious payload fragments, or exact prompts.

Accordingly, this page does not claim “zero breaches,” a seven-day completion total, or proof that no injection can succeed.
